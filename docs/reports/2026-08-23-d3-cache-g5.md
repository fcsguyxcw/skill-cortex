## 关键边界

- cache observation 只进入本地 `onDiscovery` 回调和 evaluation 工具，不进入候选卡、system prompt、
  PracticeEvent 或 Activation Memory。
- Catalog hit 不扫描 Skill package；真实宿主连续正常 turn 已验证引用稳定，resource reload 已验证引用变化并
  强制重新核验 revision，因此保留现有 `cachedSkills === skills` + metadata key，不改 cache 架构。
- cache 不改变 BM25 参数、Top-K、overlay boost、排序或候选集合。
- `load_skill` 每次仍复核路径、source hash 与完整 dependency manifest。
- 本次验证调用真实 `AgentSession.reload()`，覆盖 session 的 resource/runtime reload 路径；没有启动交互式
  TUI、自用部署或 G7。
